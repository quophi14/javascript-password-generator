# Random Password Generator

A simple Random Password Generator built with HTML, CSS, and JavaScript. The application generates random passwords containing uppercase letters, lowercase letters, numbers, and special characters.

## Features

- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Allows users to specify password length.
- Validates password length (4–64 characters).
- Shuffles generated password characters.
- Copy password functionality.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- JavaScript Math Object
- Arrays and Strings
- Spread Operator
- Clipboard API concepts
